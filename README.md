# Beam Designer

Beam Designer is a Tkinter desktop app for analyzing simply supported and
cantilever beams. It calculates reactions, shear, moment, deflection, bending
stress, and pass/fail checks, and can save designs plus export CSV and PDF
calculation sheets.

## Install packages

```powershell
python -m pip install -r requirements.txt
```

Required packages: `numpy` and `matplotlib`. Tkinter is included with standard
Windows Python installations.

## Start the app

```powershell
python app.py
```
